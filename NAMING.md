# Naming

Localist is MIT-licensed — you're free to fork, modify, and redistribute
it, including commercially, with no naming restriction attached by the
license itself.

As a courtesy, not a legal requirement: if you fork this project and
publish it under a different maintainer or organization, please give it
its own name rather than continuing to call it "Localist" or something
confusingly similar. This isn't a trademark claim or an enforcement
mechanism — just a request to keep it clear to users which project (and
which maintainer) they're actually getting support from.
